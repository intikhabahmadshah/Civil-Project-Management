Model Name Civil Site Activity Phase Classifier
Method & Algorithms Unsupervised K-Means clustering ($K=3$) chosen using the Elbow method, followed by a tuned Random Forest Classifier pipeline with StandardScaler for numeric columns and OneHotEncoder for categorical columns.
Training Dataset 3,200 multi-table records joined via SQLite relational keys from daily_site_logs (3,200), work_packages (2,800), and projects (2,500) covering 9 Pakistani cities.
Evaluation Metrics Holdout Test Set (640 samples): 96.0% Overall Accuracy, 97.2% 5-Fold Cross-Validation Accuracy, Light Prep F1: 0.97, Rebar Heavy F1: 0.96, Mass Pouring F1: 0.96.
Saved Pipeline Exported as civil_site_classifier_pipeline.joblib with 100% verified identical reload predictions.
Safety & Operational Risks Model predictions help in planning and resource tracking. They must never replace the physical site inspections of certified civil engineers.
